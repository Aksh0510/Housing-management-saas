# UX and Design System

## Current visual direction

The project already uses a premium blue/green palette aligned to the prompt: primary blue, secondary green, amber accent, white surfaces, and light-gray backgrounds. Tailwind CSS is configured centrally through `src/index.css`.

## Strengths
- clear role labels and top-level navigation
- strong use of cards, badges, and status coloring
- responsive layout and mobile bottom nav
- accessible focus states and reduced-motion support in the global stylesheet

## Gaps
- a few placeholder UI elements still exist in the shared UI layer
- deeper motion and visual differentiation could be layered in more deliberately around onboarding and dashboards
- some screens still feel more like demo macros than a fully premium workflow

## Recommendation

Continue to standardize on a single product language: concise page titles, contextual descriptions, KPI cards, empty/loading states, and clear action CTAs. Use the design system consistently across admin, member, and staff screens.
